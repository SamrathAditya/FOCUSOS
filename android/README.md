# FOCUS OS Android app

This is an Android WebView wrapper around the FOCUS OS web app. The build workflow copies the web app into Android assets and produces a debug APK.

- Application ID: com.samrathaditya.focusos
- Minimum Android: 6.0 (API 23)
- Build output: app/build/outputs/apk/debug/app-debug.apk

This MVP does not yet implement native alarm scheduling or cross-app blocking.
